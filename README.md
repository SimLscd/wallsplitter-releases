# WallSplitter

Installers for [WallSplitter](https://wallsplitter.app), the app that splits a video or an image into one file per screen of a video wall.

**Download from the website: https://wallsplitter.app/download**

| System | Installer |
| --- | --- |
| macOS, Apple silicon (M1 and later) | [WallSplitter-mac-apple-silicon.dmg](https://github.com/SimLscd/wallsplitter-releases/releases/latest/download/WallSplitter-mac-apple-silicon.dmg) |
| macOS, Intel | [WallSplitter-mac-intel.dmg](https://github.com/SimLscd/wallsplitter-releases/releases/latest/download/WallSplitter-mac-intel.dmg) |
| Windows 10 and 11 | [WallSplitter-windows-setup.exe](https://github.com/SimLscd/wallsplitter-releases/releases/latest/download/WallSplitter-windows-setup.exe) |

This repository only hosts the installers. Support: support@wallsplitter.app
